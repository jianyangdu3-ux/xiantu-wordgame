云端续缘

跨设备同步

进度默认存于本机。接上云端后，本地版与网页版自动互通，换设备也不丢进度。

☁️ 云端自动同步

手机换了、电脑换了，打开还是那个第三关。填一次密码，所有设备进度自动同步。

未连接 · 点「连接」即可开启自动同步
📖 没有密码？点这里获取（免费·1分钟）
① 打开 jsonbin.io → 用邮箱注册（免费）
② 点击左上角 API Keys → 复制长串字符（X-Master-Key）
③ 回来粘贴到上面输入框，点「连接」即可
📱 换手机 / 换电脑怎么接着玩？
① 旧设备：连接成功后，记下状态栏里的「云端存档 ID」
② 新设备：打开同一网址 → 粘贴同一个密码 + 把存档 ID 填进第二行输入框
③ 点「连接」→ 自动拉回旧进度，无缝续玩 ✓
⚠ 不填存档 ID 直接连接会新建一份空档。换设备务必填旧设备的存档 ID。
❓ 常见问题
密码是什么？就是 jsonbin.io 的 API Key（X-Master-Key），相当于你云存档的钥匙
存档 ID 在哪看？连接成功后，状态栏会显示完整 ID，随时可抄
存档 ID 丢了？回旧设备打开云端区就能看到；两个都丢只能手动导出了
连接失败？检查密码是否完整复制（别带空格）、网络是否可用
不想同步了？清空两个输入框即可断开，本地进度不受影响
